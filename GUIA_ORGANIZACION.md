## Descripción de Carpetas

### 📸 Fotos
- **Por Año**: Organiza por año de captura
- **Por Mes**: Dentro de cada año, agrupa por mes
- **Categorías**: Viajes, Familia, Eventos para fotos especiales
- **Misc**: Fotos aleatorias o no clasificadas

**Consejo**: Renombra fotos con formato `YYYY-MM-DD_descripcion.jpg`

### 🎬 Videos
- **Personales**: Videos que grabaste
- **Tutoriales**: Guías y tutoriales descargados
- **Descargas**: Videos descargados de redes sociales

### 📄 Documentos
- **Trabajo**: Documentos laborales
- **Estudio**: Apuntes y materiales educativos
- **Personales**: Escritos personales, notas
- **Trámites**: Documentos de gestión (DNI, licencia, etc.)
- **Facturas**: Recibos y facturas importantes

### 🎵 Música
- **Canciones**: Tu biblioteca musical
- **Podcasts**: Episodios descargados
- **Audiobooks**: Libros en audio
- **Playlists**: Organizadas por género o mood

### 📱 Aplicaciones
- **Herramientas**: Utilidades productivas
- **Juegos**: Aplicaciones de entretenimiento
- **Redes Sociales**: Facebook, Instagram, etc.
- **Productividad**: Calendarios, notas, tareas

### 📥 Descargas
- **Por Revisar**: Archivos nuevos sin clasificar
- **Instaladores**: APK y otros instaladores
- **Archivos**: Documentos, imágenes, etc.

### 📸 Capturas
- **Por Año**: Capturas de pantalla organizadas temporalmente
- **Favoritas**: Las más importantes

### 👥 Contactos
- **Backup**: Copias de seguridad regulares
- **Grupos**: Contactos organizados por grupos (Trabajo, Familia, etc.)

### 💬 Mensajes
- **Backup**: Copias de seguridad de conversaciones importantes
- **Importante**: Mensajes que necesitas guardar

## Mejores Prácticas de Organización

### 1. **Nomenclatura de Archivos**
```
✅ RECOMENDADO:
- 2024-07-25_Vacaciones_Playa.jpg
- Contrato_Trabajo_2024.pdf
- Factura_Electricidad_Julio_2024.pdf

❌ EVITAR:
- foto123.jpg
- documento.pdf
- archivo_final_v2_nuevo.docx
```

### 2. **Limpieza Regular**
- **Semanal**: Revisa la carpeta "Descargas" y "Por Revisar"
- **Mensual**: Organiza fotos nuevas
- **Trimestral**: Elimina duplicados y archivos obsoletos
- **Anual**: Revisa todo y archiva lo antiguo

### 3. **Copias de Seguridad**
- Realiza copias de seguridad mensuales de:
  - Documentos importantes
  - Fotos de valor sentimental
  - Contactos
  - Mensajes importantes

**Opciones de respaldo**:
- Google Drive
- OneDrive
- iCloud (iPhone)
- Dropbox
- Almacenamiento externo

### 4. **Eliminar con Seguridad**
Antes de eliminar archivos:
- Verifica duplicados
- Confirma que no necesitas el archivo
- Si es importante, haz respaldo primero
- Vacía la papelera después

### 5. **Etiquetas y Búsqueda**
Si tu teléfono lo permite:
- Usa etiquetas o colores para prioridad
- Utiliza palabras clave en nombres de archivo
- Aprovecha la búsqueda del dispositivo

## Consejos por Tipo de Teléfono

### 📱 Android
- Usa Google Files para gestionar automáticamente archivos
- Vincula Google Drive para copias de seguridad
- Usa Smart Storage para liberar espacio
- Mantén actualizado el Administrador de archivos

### 🍎 iPhone
- Usa la app Archivos nativa
- Configura iCloud para copias de seguridad automáticas
- Organiza carpetas en "Mi iPhone"
- Revisa almacenamiento en Ajustes

## Mantenimiento Mensual

**Primera semana del mes:**
1. Revisa carpeta "Por Revisar/Descargas"
2. Clasifica archivos nuevos
3. Elimina archivos duplicados
4. Realiza copia de seguridad
5. Verifica espacio disponible

---

## Almacenamiento: Consejos para Liberar Espacio

### Archivos que Tomar Menos Espacio
1. **Fotos y Videos**: Comprime antes de guardar
2. **Música**: Usa streaming en lugar de descargas
3. **Aplicaciones**: Desinstala las que no uses
4. **Caché**: Limpia regularmente
5. **Archivos Grandes**: Mueve a almacenamiento en nube

### Tamaños Típicos
- Foto promedio: 2-5 MB
- Video 1 minuto: 30-50 MB
- Documento PDF: 0.5-2 MB
- Aplicación promedio: 50-200 MB

---

## Conclusión

Una estructura de carpetas bien organizada:
- ✅ Ahorra tiempo buscando archivos
- ✅ Facilita copias de seguridad
- ✅ Protege datos importantes
- ✅ Optimiza el almacenamiento
- ✅ Reduce estrés y frustración

**Recuerda**: La consistencia es clave. Mantén el sistema desde el inicio.
