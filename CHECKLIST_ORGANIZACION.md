# ✅ Checklist de Organización de Archivos del Teléfono

## Fase 1: Preparación (Día 1-2)

- [ ] Realizar copia de seguridad completa del teléfono
- [ ] Liberar espacio en el almacenamiento (al menos 10%)
- [ ] Descargar gestor de archivos (si es necesario)
- [ ] Revisar espacio disponible total

## Fase 2: Crear Estructura (Día 3)

### En tu teléfono:
- [ ] Crear carpeta "Mi Organizacion" o "Archivos"
- [ ] Crear subcarpetas principales:
  - [ ] Fotos
  - [ ] Videos
  - [ ] Documentos
  - [ ] Música
  - [ ] Aplicaciones
  - [ ] Descargas
  - [ ] Capturas
  - [ ] Contactos
  - [ ] Mensajes

## Fase 3: Organizar Fotos (Día 4-5)

- [ ] Crear carpetas por año (2024, 2025, etc.)
- [ ] Dentro de cada año, crear por mes (01-Enero, 02-Febrero, etc.)
- [ ] Crear subcarpetas especiales:
  - [ ] Viajes
  - [ ] Familia
  - [ ] Eventos
  - [ ] Misc
- [ ] Mover fotos a carpetas correspondientes
- [ ] Renombrar fotos sin nombre (formato: YYYY-MM-DD_descripcion)

## Fase 4: Organizar Documentos (Día 6)

- [ ] Crear subcarpetas:
  - [ ] Trabajo
  - [ ] Estudio
  - [ ] Personales
  - [ ] Trámites
  - [ ] Facturas
- [ ] Clasificar y mover documentos
- [ ] Renombrar documentos sin nombre clara
- [ ] Eliminar duplicados

## Fase 5: Organizar Multimedia (Día 7-8)

### Música:
- [ ] Crear carpetas: Canciones, Podcasts, Audiobooks, Playlists
- [ ] Mover archivos de música
- [ ] Eliminar archivos corruptos

### Videos:
- [ ] Crear carpetas: Personales, Tutoriales, Descargas
- [ ] Mover videos
- [ ] Renombrar videos importantes

## Fase 6: Limpiar Descarga (Día 9)

- [ ] Revisar carpeta de Descargas completa
- [ ] Clasificar cada archivo
- [ ] Mover a carpeta permanente o eliminar
- [ ] Crear sistema para futuras descargas

## Fase 7: Organizar Capturas (Día 10)

- [ ] Crear carpetas por año
- [ ] Crear subcarpeta "Favoritas"
- [ ] Mover capturas a carpetas correspondientes
- [ ] Eliminar capturas innecesarias

## Fase 8: Contactos y Mensajes (Día 11)

### Contactos:
- [ ] Hacer backup de contactos
- [ ] Crear grupos (Trabajo, Familia, Amigos, etc.)
- [ ] Organizar contactos en grupos

### Mensajes:
- [ ] Hacer backup de conversaciones importantes
- [ ] Eliminar mensajes antiguos si es necesario
- [ ] Marcar conversaciones importantes

## Fase 9: Aplicaciones (Día 12)

- [ ] Hacer inventario de aplicaciones instaladas
- [ ] Categorizar en: Herramientas, Juegos, Redes Sociales, Productividad
- [ ] Desinstalar aplicaciones no usadas
- [ ] Actualizar aplicaciones

## Fase 10: Revisión y Ajustes (Día 13)

- [ ] Verificar que todo esté en su lugar
- [ ] Ajustar categorías si es necesario
- [ ] Crear reglas de organización
- [ ] Documentar tu sistema personalizado

## Fase 11: Copias de Seguridad (Día 14)

- [ ] Configurar backup automático en:
  - [ ] Google Drive (Android)
  - [ ] OneDrive
  - [ ] Dropbox
  - [ ] iCloud (iPhone)
- [ ] Hacer respaldo manual en computadora
- [ ] Verificar que los backups funcionan

## Fase 12: Mantenimiento (Continuo)

- [ ] **Semanal**: Revisar carpeta "Descargas"
- [ ] **Mensual**: 
  - [ ] Organizar nuevas fotos
  - [ ] Limpiar archivos temporales
  - [ ] Revisar espacio disponible
  - [ ] Hacer copia de seguridad
- [ ] **Trimestral**:
  - [ ] Eliminar duplicados
  - [ ] Revisar apps no usadas
  - [ ] Actualizar sistema de archivos si es necesario
- [ ] **Anual**:
  - [ ] Revisar y archivar años anteriores
  - [ ] Eliminar archivos obsoletos
  - [ ] Optimizar almacenamiento

## Herramientas Recomendadas para Cada Teléfono

### Android
- [ ] Google Files App
- [ ] Google Drive
- [ ] Microsoft OneDrive
- [ ] Dropbox
- [ ] SD Maid (limpieza)

### iPhone
- [ ] Apple Archivos
- [ ] iCloud
- [ ] Google Drive
- [ ] OneDrive
- [ ] Dropbox

## Consejos Finales

✅ **Hazlo gradualmente**: No trates de hacerlo todo en un día
✅ **Sé consistente**: Sigue las reglas de nombres que establezas
✅ **Revisa regularmente**: El mantenimiento es clave
✅ **Haz backups**: Nunca es demasiado importante
✅ **Adapta el sistema**: Modifica según tus necesidades personales

## Notación de Nomenclatura Estándar

### Fotos:
```
YYYY-MM-DD_DESCRIPCION.jpg
2024-07-25_Playa_Vacaciones.jpg
2024-12-25_Navidad_Familia.jpg
```

### Documentos:
```
[Año]-[Mes]-[Tipo]_DESCRIPCION.pdf
2024-07-Factura_Electricidad_Julio.pdf
2024-06-Contrato_Trabajo_Renovacion.pdf
```

### Videos:
```
YYYY-MM-DD_[Categoría]_DESCRIPCION.mp4
2024-07-25_Tutorial_Como_Organizar_Archivos.mp4
```

---

**Duración estimada del proceso completo**: 2-3 semanas
**Tiempo de mantenimiento mensual**: 30-45 minutos
